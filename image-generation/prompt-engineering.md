# Image Generation Prompt Engineering

A useful visual prompt specifies the elements that matter to the intended result.

## Prompt structure

- Subject
- Environment
- Composition
- Camera or viewpoint
- Lighting
- Color
- Materials and texture
- Mood or visual intent
- Image format or aspect ratio when supported

## Workflow

1. Define the concept.
2. Establish composition.
3. Add lighting and color.
4. Add technical constraints only when useful.
5. Generate variations.
6. Evaluate the image against the original intent.
7. Refine one variable at a time.

Avoid stacking vague style terms without specifying what they should change in the image.
