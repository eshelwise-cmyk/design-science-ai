# Design Science AI

A structured knowledge and skill library for visual design, photography, cinematography, image generation, color science, and creator workflows.

## Areas

- Design foundations
- Photography systems
- Cinematography analysis
- Image generation
- Color science and grading
- Video editing and creator workflows

## Approach

Connect visual principles with technical practice. Analyze composition, light, color, framing, camera behavior, image-generation controls, and editing decisions as related systems.

## Status

Initial knowledge architecture. Content is being built in modular skills, workflows, tutorials, and reference material.
