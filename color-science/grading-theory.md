# Color Grading Theory

Color grading combines technical correction with creative image design.

## Technical stage

Evaluate:

- exposure
- white balance
- contrast
- dynamic range
- color-space transforms
- clipping

## Creative stage

Shape:

- palette
- hue relationships
- saturation
- tonal separation
- skin-tone consistency
- shot-to-shot continuity

A useful workflow separates technical normalization from creative look development so problems can be diagnosed independently.
