# Visual Control

Image-generation workflows should control the visual variables that define the composition.

## Control variables

- Subject placement
- Camera viewpoint
- Lens perspective
- Depth of field
- Lighting direction
- Contrast
- Color relationships
- Background structure
- Foreground elements

Reference images can be used to communicate composition, subject relationships, lighting, or style. Treat each reference as a source of specific visual information rather than copying an entire image by default.
