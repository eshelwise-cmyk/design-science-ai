# Design Principles

## Core principles

- Balance
- Contrast
- Emphasis
- Hierarchy
- Proportion
- Rhythm
- Repetition
- Scale
- Unity
- Variety

## Visual analysis

When evaluating a design, identify the dominant visual structure first, then examine relationships among elements.

Ask:

1. What attracts attention first?
2. How does the eye move through the composition?
3. What creates balance or tension?
4. Which elements establish hierarchy?
5. What creates unity?

## Golden ratio

The golden ratio can be used as a proportional construction method, but it should be treated as one compositional tool rather than a universal rule for beauty.
