# Creator Production Pipeline

## 1. Concept

Define subject, audience, visual intent, and delivery format.

## 2. Pre-production

Plan composition, references, lighting, locations, camera requirements, and shot coverage.

## 3. Capture or generation

Create the source material while preserving enough image information for editing and grading.

## 4. Edit

Build structure, pacing, continuity, and story.

## 5. Color

Normalize footage, match shots, then develop the creative look.

## 6. Finishing

Check image quality, audio, titles, graphics, export settings, and platform requirements.

## 7. Review

Evaluate the final output on the intended delivery environment before publishing.
